## Core Project Architecture & Stack

- Rust workspace, edition 2024, GPL-3.0-only. `crates/core` (`keeplight-core`): the engine every front end calls. `crates/app` (`keeplight`): the Slint window and the keeper (`--keep`), which only pass requests to core and show results. `crates/cli` (`keeplight-cli`): the command line and the MCP server (`keeplight-cli mcp`).
- Core modules: `sdk` (own sync OpenRGB SDK client, protocol 3; `openrgb2` is banned, GPL-2.0-only), `sdk::wire` (framing, `Reader`/`Writer`, `update_mode`/`update_leds` payloads), `device` (model, full `Mode` fields so modes can be sent back unchanged), `keep` (setup file, capture, fit, put back, `keep_now`/`put_back_now`), `testing` (fake SDK server and sample devices; `cfg(test)` or feature `testing`).
- Keeper logic stays in core, not window code: owner-approved design request (2026-11-13, via the Mac coordinating session). Keeplight is the fleet's first app on the agent-interface kit (pilot merged as #16); every front end goes through `core::agent::Engine`.
- Setup file: `%LOCALAPPDATA%\Keeplight\setup.json` (`%LOCALAPPDATA%\Keeplight Dev` for a dev build; `KEEPLIGHT_DATA_DIR`, older name `KEEPLIGHT_DATA`, overrides the folder). Format version 1; a newer or unreadable file is never saved over.
- Two identities (`crates/core/build.rs`, `core::scratch`): only a release build from a full checkout is the release app; debug and worktree builds are the dev app (`Keeplight Dev` folder and startup entry, so its own keeper mutex and stop event; no update check or downloads; refuses 127.0.0.1:6742 unless `KEEPLIGHT_NETWORK=live`). `KEEPLIGHT_SCRATCH=1` (set for every `cargo test`/`cargo run` by `.cargo/config.toml`, and by the smoke script) needs `KEEPLIGHT_DATA_DIR` (temp, not the real profile), `KEEPLIGHT_OPENRGB` (loopback, not 6742) and a test `KEEPLIGHT_STARTUP_NAME`, and refuses `KEEPLIGHT_NETWORK=live`. Recipe in CONTRIBUTING.md and AGENTS.md.
- Theme: `crates/app/ui/theme.slint` is a byte copy of Modlist Launcher's (c04e8d0). Fixes land there first.
- CI: `ci.yml` on GitHub-hosted runners (public repo): `Lint, test, and build` on windows-latest, `Dependency policy` (cargo-deny) on ubuntu-latest, both required. `main-build.yml` and `release.yml` run only when started by hand (workflow_dispatch; see Active Task State, 2026-11-18). A `changes` job on ubuntu-latest skips both on docs-only PRs (root `*.md`, `docs/**/*.md`, `LICENSE*`; 2026-11-17, fleet standard in agentic-instructions `docs/github-actions-maintenance.md`).
